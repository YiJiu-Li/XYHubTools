# XY Unity 智能体

Unity 菜单：`XY Tools → AI → XY Unity 智能体`。也可在 XY 编辑器工具集的 **AI** 分类打开。

日常直接在当前工程的 Codex 聊天中描述需求，例如：“检查 1001 点位第二次进入后按钮不响应的原因，先别改代码。”无需打开本面板、选择工作流或复制指令。Codex 根据任务匹配 Skill，通过 XY MCP 查询所需的工程、场景和对象状态。

首次在另一个工程使用时，点击一次“安装 / 更新当前工程智能体技能包”，并确认该工程的 XY MCP 连接正常。三个 Skill 安装到工程 `.agents/skills`，不改全局技能、AGENTS.md 或模型账户配置。若没有自动匹配，可在聊天中显式使用下表的 Skill；未发现安装时重新打开聊天或重启客户端。

| 专项 | Skill | 使用示例 |
|---|---|---|
| Unity/Rokid 开发 | `$xy-unity-agent` | 检查点位第二次进入后按钮失效 |
| Shader/VFX 渲染 | `$xy-unity-shader` | 实现溶解材质并检查移动端效果 |
| 桌面 Agent 开发 | `$xy-agent-desktop-dev` | 检查 Tauri 流式事件取消后仍刷新的原因 |

技能按需求匹配，不自动换模型或创建子智能体。Shader/VFX 与桌面 Agent 来源文件的整理取舍见 [三份智能体审阅](AGENT-SOURCE-REVIEW.md)。

面板主要用于安装、更新和查看状态。“高级选项：手动生成交接任务”默认收起；仅在需要固定当前上下文快照或交给另一个聊天时展开。这里仍可选择任务、执行范围，并把工程、场景和最多 16 个选中对象复制为任务指令。

六类工作流：问题诊断、点位开发、音视频流程、手势交互、资源与加载检查、批量编辑与验证。日常在聊天中用“先看看、不要改”或“修复并验证”限定范围；高级交接选项默认“仅分析”。

这是一套工作流型智能体：由现有 Codex 负责推理和执行，XY MCP 提供 Unity 操作，面板提供任务和工程上下文。它不是在 Unity 内另建的聊天模型，没有 API Key 配置，也不会自动发送任务或上传对话。

## 更新与备份

插件中的 `Agent~/skills` 是分发源，`agent.json` 是主版本、文件清单和工作流预设，`profiles/*.json` 声明专项技能。Skill 安装器在开始前校验所有安装源和已有副本，只更新本插件管理且未被手工修改的副本；有本地改动、额外文件或来源不明时拒绝覆盖，保留现有内容。版本降级也会被阻止。

更新前旧副本移到当前工程 `.agents/xy-agent-backups/<随机目录>`，不参与 Skill 自动发现。每个新副本在暂存目录准备完整后切换；该项安装失败会尽可能恢复旧目录。三个技能逐项安装，不是跨技能事务；IO 错误时报告此前已完成项，可修正问题后重试。恢复时先保存当前改动，再将选定备份移回原 Skill 位置。

`scripts/inspect_project.py` 是可选只读盘点工具，检查模块配置、asmdef、模块内重复 GUID 和模板差异；它不验证整个工程的 GUID 唯一性或运行行为。运行产生的 `__pycache__` 可使安装器把副本视为新增文件；更新前请保留需要的本地内容并清理生成的缓存。

历史资料取舍见 [DERIVATION.md](DERIVATION.md)。发布插件时只带提炼后的通用知识，不带原始导出 ZIP、私有地址或完整聊天。当前版本未扩展 Timeline 专项能力。

本版按 OpenAI 的 [Skills 文档](https://learn.chatgpt.com/docs/build-skills) 使用工程级 `.agents/skills` 和 `SKILL.md`，复用既有 MCP 工具。
